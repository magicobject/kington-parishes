Help / Getting set up

Setting up your laptop

A one-off job, about twenty minutes. Once this is done, you won't need to repeat it — every future change starts from step one of making a change.

Five things to do, in order

Install, sign up, connect, ask

1. Install Claude Desktop

Claude Desktop is the app you'll use whenever you want something on the website changed — specifically its Code tab (also called Claude Code), which is what lets Claude read and edit files on your laptop and talk to GitHub on your behalf. An ordinary chat elsewhere in the app can't do either of those. Download it from claude.ai/download and sign in (or create an account if you don't already have one).

2. Install two free tools Claude needs

Claude Code works through your laptop's own tools rather than bringing its own, so two small, free programs need installing first — both one-off, both a plain "next, next, finish" installer with no settings to change: Git (the actual program behind everything described in Git & GitHub, in plain English) and Node.js (choose the "LTS" version) — the toolkit this site's build process and automatic tests run on.

3. Create a free GitHub account

GitHub is where the website's master copy lives — see Git & GitHub, in plain English. Sign up at github.com/signup and keep your username and password somewhere safe, like a password manager.

Then turn on two-factor authentication (2FA) in your GitHub account settings, under Password and authentication. It's a quick one-off step — after your password, GitHub also asks for a one-time code from an app on your phone — and it matters: this account will have the ability to change a real, public website, so it's worth properly securing.

4. Ask for access

Send your new GitHub username to whoever currently looks after the website, so they can add you to the project. Get in touch at web@kingtonparishes.org.uk.

5. Open the Code tab and ask Claude to fetch the site

Once you have access, open Claude Desktop's Code tab and ask Claude to get a working copy of the Kington Parishes website ready — technically this is called "cloning the repository", but you can just say it in plain English and Claude will handle the actual command. It'll ask where on your laptop to put it (anywhere is fine — a folder called Documents is a sensible default) and, from then on, that's the one you'll point the Code tab at each time you come back to make another change. The first time Claude needs to connect to GitHub on your behalf, a browser window may pop up asking you to sign in — that's expected, and only happens once.

If Claude ever asks which address to fetch, it's https://github.com/magicobject/kington-parishes.git — see the technical details page for more on where the code lives.

Ready?

That's it — from here on, no technical knowledge is required. Every future change just means describing what you'd like in plain English, the same way you'd ask a person to do it. Making a change walks through exactly what happens each time you ask Claude for something.
