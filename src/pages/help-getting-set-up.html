Help / Getting set up

Setting up your laptop

A one-off job, about fifteen minutes. Once this is done, you won't need to repeat it — every future change starts from step one of making a change.

Four things to do, in order

Install, sign up, connect, ask

1. Install Claude Desktop

Claude Desktop is the app you'll talk to whenever you want something on the website changed. Download it from claude.ai/download and sign in (or create an account if you don't already have one).

2. Create a free GitHub account

GitHub is where the website's master copy lives — see Git & GitHub, in plain English. Sign up at github.com/signup and keep your username and password somewhere safe, like a password manager.

3. Ask for access

Send your new GitHub username to whoever currently looks after the website, so they can add you to the project. Get in touch at web@kingtonparishes.org.uk.

4. Open Claude Desktop and ask

Once you have access, open Claude Desktop and say you'd like to make a change to the Kington Parishes website. The first time it needs to connect to GitHub on your behalf, a browser window may pop up asking you to sign in — that's expected, and only happens once.
