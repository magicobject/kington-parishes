How this website gets updated

You don't need to know how to code. This page explains, in plain English, how changes get made to this site — and how you can make one yourself, with help from an AI assistant called Claude. Once your laptop is set up — a one-off job — zero technical knowledge is needed for anything that follows: every future change is just a plain-English conversation, the same way you'd ask a person to do it.

The short version

What happens when you ask for a change

Every change to this website — big or small — follows the same six steps. You only ever do the first one; Claude takes care of the rest.

1. You describe the change

In your own words — "add this event to the calendar" or "the phone number on the Contact page is wrong". No technical detail needed.

2. Claude edits the files

On your own laptop, Claude finds the right page and makes the change — you can see exactly what it changed before it goes any further.

3. Claude checks its own work

The site's automatic tests run, and Claude checks the page still passes its security and accessibility rules — nothing goes live untested.

4. Claude saves it to GitHub

This step is called a "push" — it's the moment your change leaves your laptop and joins the master copy the live site is built from.

5. The live site rebuilds itself

A process behind the scenes notices the new version on GitHub and publishes it automatically — usually in well under a minute, with nothing more for you to do.

6. You watch it appear

Keep an eye on /updates — every change is logged there, newest first, so you can confirm yours has gone live.

Two names worth knowing

What are "Git" and "GitHub"?

You'll see these words come up, so it's worth knowing what they mean — even though Claude handles both for you and you'll never need to use either directly.

Git

The record-keeping system behind the website's files. It saves every version of every change ever made, like an extremely thorough undo history — nothing is ever truly lost.

GitHub

The website where those files live online. It's the master copy the live site is built from, and where Claude sends ("pushes") your changes once they're checked and ready.
