Sitemap: https://kington-parishes.magicobject.workers.dev/sitemap.xml

# This is a proof-of-concept build, not the parishes' real production
# website — every page also carries <meta name="robots" content="noindex,
# nofollow">. Crawling is deliberately still allowed (rather than
# Disallow: /) so that meta tag is actually seen and honoured; blocking
# crawling here would risk the bare URL still getting indexed with no
# noindex signal visible. sitemap.xml (scripts/build.mjs, regenerated on
# every build) is published anyway — a sitemap is a discovery hint, not an
# indexing override, so listing noindex pages in it is harmless, and it
# means the sitemap is already correct and ready the moment SITE_URL points
# at the real domain and the noindex tags come off, rather than something
# to remember to build later.
