    Help / Getting set up

    Setting up your laptop

    A one-off job, about fifteen minutes — and most of that is just waiting for Claude to finish, not typing. Once this is done, you won't need to repeat it — every future change starts from step one of making a change.

    Four things to do, in order

    Install, sign up, ask, wait

    1. Install Claude Desktop

    Claude Desktop is the app you'll use whenever you want something on the website changed — specifically its Code tab (also called Claude Code), which is what lets Claude read and edit files on your laptop and talk to GitHub on your behalf. An ordinary chat elsewhere in the app can't do either of those. Download it from claude.ai/download and sign in (or create an account if you don't already have one).

    2. Create a free GitHub account

    GitHub is where the website's master copy lives — see Git & GitHub, in plain English. Sign up at github.com/signup and keep your username and password somewhere safe, like a password manager.

    Then turn on two-factor authentication (2FA) in your GitHub account settings, under Password and authentication. It's a quick one-off step — after your password, GitHub also asks for a one-time code from an app on your phone — and it matters: this account will have the ability to change a real, public website, so it's worth properly securing.

    3. Ask for access

    Once your GitHub account is created, tell Greg your new username so he can add you to the project — without that, Claude won't be able to save your changes to the site's code. Get in touch at web@kingtonparishes.org.uk. You'll get an email invitation from GitHub — accept it before going any further, or Claude won't be able to save your changes later on.

    4. Open the Code tab, paste this, and wait

    Open Claude Desktop's Code tab, copy the box below into it exactly as it is, and send it. Claude will check your laptop has what it needs, fetch a working copy of the website, and tell you when it's ready — there's nothing else to do while it works, other than answer if it asks you something.

    The first time Claude needs to connect to GitHub on your behalf, a browser window may pop up asking you to sign in — that's expected, and only happens once. If you'd like to know more about what any of this means, see Git & GitHub, in plain English and the technical details page.

    Ready?

    That's it — from here on, no technical knowledge is required. Every future change just means describing what you'd like in plain English, the same way you'd ask a person to do it. Making a change walks through exactly what happens each time you ask Claude for something.
